## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/` (one file per ticket). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` plus `docs/adr/` at the repo root, both created when first needed. See `docs/agents/domain.md`.
